# Lightbox 右上角控件定位收口存档

日期：2026-05-28

## 本轮目标

- 补齐大图查看页更明确的关闭 / 下载入口
- 不做重型工具栏
- 控件不压图片主体内容

## 最终定稿

- 大图查看页控件保留为两个轻量圆形按钮：
  - `下载`
  - `关闭`
- 控件最终位置确定为：
  - 图片外侧
  - 图片上方
  - 靠图片右上角
  - 整组控件右边缘与图片最右边对齐

## 本轮过程结论

- 早期版本的问题不是只有样式，而是定位语义多次偏了：
  - 放在整页右上角：不对
  - 放在图片内部右上角：不对
  - 放在图片右侧外面：也不是最终要的位置
- 最终用户确认的位置语义是：
  - `图片外侧的右上角`
  - 不是页面右上角
  - 不是图片内部右上角
  - 不是图片右侧中上部

## 实现结果

- `Lightbox` 控件当前已改为挂在图片容器角点外侧。
- 控件定位已按最终语义收口。
- 触摸 / 点击时仍按 `data-lightbox-control` 控制区处理，避免误触发空白关闭。

## 验证状态

- 多次 `npm run build` 通过
- 当前仍只有原有 Vite chunk-size warning
- 本地浏览器已反复检查：
  - 控件显示
  - 下载按钮可点击
  - 关闭按钮可点击
  - 控件不再压在图片内容上

## 当前可作为停点

- 这一轮已经可以作为 `Lightbox` 右上角控件的定稿停点。
- 用户已明确确认：`不用，就这样很好`
