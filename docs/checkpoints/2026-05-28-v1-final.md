# V1 最终版存档

日期：2026-05-28

## 版本定义

- 当前版本定义为：`V1 最终版`
- 这是一个：
  - 个人优先
  - 通用用途
  - 可直接使用的图像工作台版本
- 这不是：
  - 家具版
  - 设计师垂直版
  - 网站接入版
  - 模板系统版
  - 项目制工作流版

## 产品定位

- 主路径是 `作品流`
- `连续创作` 保留为进阶模式
- 左侧 `生成台` 是主操作区
- 右侧保持轻量结果区
- 不做重型工作区，不做多业务块堆叠

## V1 最终版已定内容

### 1. 用户界面口径

- 已统一为个人版表达
- 已移除上一版残留的上游宣传 / 版权导向展示内容
- 用户可见主命名已稳定为：
  - `作品流`
  - `连续创作`
  - `生成台`
  - `负面提示`

### 2. 左侧生成台

- 输入区初始高度已抬高
- 顶部提示已压简
- `@ 引用` 保留
- 负面提示词区域已中文化并补齐常用约束

### 3. 右侧结果区

- 右侧已压轻，不再是重型 hero / 工作区结构
- 卡片密度、圆角、阴影已做过一轮统一

### 4. 大图查看页

- `Lightbox` 已补明确操作入口：
  - `下载`
  - `关闭`
- 控件最终位置已定为：
  - 图片外侧
  - 图片上方
  - 靠图片右上角
  - 整组控件右边缘与图片最右边对齐

## 明确不纳入 V1 最终版的内容

- 不加入行业预设风格体系
- 不加入室内 / 家具 / 软装 / 设计师专属模板
- 不加入项目管理、客户管理、网站账号联动
- 不加入品牌库 / 产品库 / 材质库接入
- 不把右侧重新做重
- 不在这一版继续扩“可用型网站接入版”逻辑

## 当前验证状态

- 多次 `npm run build` 通过
- 当前已知仅剩原有 Vite chunk-size warning
- 浏览器已反复验收关键路径，包括：
  - 主界面布局
  - `作品流 / 连续创作`
  - 左侧生成台
  - 详情弹层
  - 大图查看页

## 作为后续基线的建议

- 后续如果继续开发，应以 `V1 最终版` 为冻结基线。
- 下一阶段如要扩展，应单独立项，不要直接把 V1 再做回重型版本。
- 合理的后续方向只能从下面几类中单开：
  - 纯视觉精修
  - 性能优化
  - 网站接入版
  - 垂直行业版
