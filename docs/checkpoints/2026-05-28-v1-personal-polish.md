  - 非行业化

## 本轮完成内容

### 1. 口径与范围界定

- 首页、设置、帮助、连续创作相关入口文案已统一到个人版口径。
- 顶部主模式已统一为：
  - `作品流`
  - `连续创作`
- 已明确：
  - `作品流` 是默认主路径
  - `连续创作` 是进阶模式，适合多轮迭代、引用历史图、分支比较

### 2. README 与对外说明去上游化

- `README.md` 已移除上游仓库宣传、在线体验、赞助、Star History 等作者导向内容。
- `README.md` 已改为个人版说明书口径。

### 3. 左侧生成台微调

- 左侧生成台桌面宽度已收窄一档。
- 文生图输入框初始高度已抬高到更接近 3 行。
- 顶部提示区已简化：
  - `Composer` -> `生成台`
  - 发送提示胶囊已移除
  - 仅保留 `@ 引用`
- `Negative Prompt` 已中文化为 `负面提示`

### 4. 负面提示词优化

- 负面提示常用约束已补到更实用的 5 个常用项：
  - `避免水印`
  - `避免文字`
  - `避免畸形手部`
  - `避免低清晰度`
  - `避免背景杂乱`
- 相关说明文字已统一为中文，不再混用 `Avoid` 口径。

### 5. 右侧与卡片轻量抛光

- 右侧 `作品流` 顶栏已压轻。
- 统计块尺寸和密度已进一步收紧。
- 任务卡圆角、选中阴影已统一收一档，整体视觉更一致。

- 浏览器已反复验收桌面主界面与若干关键点：
  - 顶部模式切换
  - 左侧生成台

  - 连续创作 / 设置 / 帮助文案口径

## 建议的停点

当前状态已经适合作为 `个人版 V1 初稿` 的阶段性存档。

如果后续继续，建议只从这几类里选一项推进：

- 纯视觉微调：
  - 卡片间距
  - 圆角
  - 阴影
  - 统一密度
- 内部命名清理：
  - 仅限代码内部残留的 `Agent` 命名
  - 不影响用户界面
- 性能优化：
  - chunk 拆分
  - 非阻塞

不建议下一步做的事：

- 不要重新引入家具/室内/设计师垂直逻辑
- 不要在 V1 里扩模板系统、预设体系、项目制工作流
- 不要把右侧重新做重
