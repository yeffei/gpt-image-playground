# V2 Phase Boundary

更新时间：2026-05-28

## 1. V2 不是 V1 的继续打补丁

V2 应被视为新的产品阶段，而不是在 V1 上直接不断加功能。

## 2. V1 本阶段任务

V1 当前只做三件事：

- 保持个人版范围稳定
- 做 Windows EXE 封装
- 保证桌面端可长期自用

## 3. V2 启动前提

只有在以下条件满足后，才建议正式进入 V2：

- V1 UI 定稿
- V1 桌面端主流程跑通
- 本地保存、下载、导出可用
- 桌面封装构建链路稳定

## 4. V2 可承接的方向

- 商业版功能架构
- 模板库正式产品化
- 账户 / 注册 / 登录
- 充值 / 积分 / 消耗
- 服务端代理与计费链路
- 网站接入与多端同步

## 5. 当前执行原则

- 不把 V2 功能直接混到 V1 桌面封装中
- 先交付一个稳定的个人版桌面工具
- 再进入新的功能阶段
