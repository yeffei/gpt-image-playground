# 提示词优化器实现清单

基于 `prompt-optimizer-unified-design.md`，第一版只做最小可用能力。

## 一、入口

- 在当前输入区增加一个按钮：`优化提示词`
- 不新增独立页面
- 不让用户手动选择 `文生图 / 图生图`

## 二、模式判断

- 无参考图、无遮罩：走 `Text-to-Image`
- 有参考图或有遮罩：走 `Image-to-Image`
- 即使有多张参考图，第一版用户文案仍统一显示为 `图生图`

## 三、发送给优化器的输入

- 当前主提示词
- 当前是否有参考图
- 当前是否有遮罩
- 当前尺寸
- 当前负面提示词

## 四、第一版输出字段

- 优化说明
- 优化后的主提示词
- Negative Prompt
- 推荐比例
- 可选增强项

## 五、回填规则

- 主提示词：允许一键应用
- Negative Prompt：默认追加合并并去重
- 推荐比例：只展示，不自动改
- 可选增强项：只展示，不自动改

## 五点五、边界说明

- 优化器只整理提示词和负面提示词
- 不承担审核、拦截或是否允许提交的判断

## 六、界面形态

- 点击 `优化提示词` 后，打开一个轻量结果面板
- 面板内展示输出结果
- 面板底部保留动作按钮：
  - `应用优化结果`
  - `复制结果`
  - `关闭`

## 七、第一版不做

- 多轮对话式优化
- 历史优化记录
- 多版本对比
- 自动改尺寸参数
- 用户手动切换优化模式
- 提示词评分系统

## 八、验收标准

- 无参考图时能正确走文生图优化
- 有参考图时能正确走图生图优化
- 不额外出现第三种用户感知模式文案
- 优化结果能稳定生成主提示词和负面提示词
- 应用结果后不破坏现有生成流程
- 面板不挤压当前主布局
