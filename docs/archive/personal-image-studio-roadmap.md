## 1. 产品定位

这个产品当前应被定义为：

- 面向个人独立使用的通用图像工作台
- 不绑定特定行业、商品库或网站业务流程
- 任何人都可以直接拿来写提示词、挂参考图、保存历史、继续迭代

一句话概括：

> 做一个轻量、顺手、可长期使用的个人版 V1 图像工作台。

## 2. 当前原则

### 2.1 必须保留的核心能力

- 自由写提示词
- 上传参考图
- 遮罩编辑
- 调整尺寸、质量、格式、数量
- 保存历史记录
- 收藏与复用方案
- 下载结果与导出数据

### 2.2 当前不做的方向

- 不引入特定行业模板
- 不引入商品、项目、客户等业务结构
- 不引入复杂协作和重型管理系统
- 不把界面做成面向某个职业的专用工作台

## 3. V1 目标

V1 的目标不是功能越多越好，而是：

- 通用
- 轻量
- 顺手
- 稳定

也就是让一个普通个人用户打开后就能直接开始使用，而不需要理解额外的行业背景。

## 4. V1 应保留和优化的方向

### 4.1 输入与起图效率

- 提示词输入顺畅
- 参考图添加与替换顺畅
- 常用参数位置清楚
- 起图动作明确

### 4.2 历史与复用

- 任务记录易浏览
- 收藏方案易筛选
- 从历史继续生成足够直接
- 搜索和状态过滤保持高可用

### 4.3 输出与管理

- 单张下载
- 批量下载
- 导出与导入
- 本地数据安全可控

### 4.4 标准版界面原则

- 不堆过多专业控制项
- 不出现过强的行业术语
- 不做大而重的风格库
- 保持右侧是结果流，左侧是输入与控制

## 5. V1 不建议优先做

- 行业模板
- 任务预设库
- 重型项目管理
- 多层级方案系统
- 面向特定职业的流程化入口

## 6. 后续扩展原则

如果未来真的需要扩展到特定场景，应遵守：

- 标准版继续保持通用
- 扩展能力不反向污染标准版主流程
- 能作为附加层存在，而不是改变基础产品定义

## 7. 当前下一步

标准版后续更适合优先做这些事情：

1. 检查并清理残留的垂直语境
2. 收紧通用版文案与信息架构
3. 优化历史复用与继续生成体验
4. 保持构建稳定，避免无效功能膨胀
